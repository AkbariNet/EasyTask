# 📖 Overview

EasyTask is a modern task automation application designed to execute actions at a specific time without requiring user interaction.

Whether you want to automatically shut down your PC after downloading files, launch an application at a scheduled time, or terminate a running process, EasyTask handles everything for you.

Every completed task is automatically saved in **Recent Tasks**, allowing you to review your automation history whenever you want.

---

# ✨ Features

## ⏰ Smart Task Scheduling

Create scheduled tasks with just a few clicks.

Each task will automatically execute at the specified time.

---

## ⚡ Supported Actions

EasyTask can perform the following actions automatically:

- Shutdown Windows
- Restart Windows
- Put the computer into Sleep Mode
- Launch any application
- End (Kill) a selected process/application

---

## 📜 Recent Tasks

Every executed task is automatically moved to the **Recent Tasks** section.

There you can view:

- Completed tasks
- Execution time
- Action history

---

## 🌍 Multi-Language Support

EasyTask supports **8+ international languages**, making the application accessible for users around the world.

Language can be changed instantly from the settings panel.

---

## ⚙️ Advanced Settings

Customize EasyTask exactly the way you like.

Available options include:

- Child Lock (Password Protection)
- Enable / Disable Notifications
- Enable / Disable Timer Window
- Change Application Theme
- Select Application Language
- Customize user preferences

---

## 🔒 Intrusion Protection

EasyTask includes an optional security feature called **Intrusion Protection**.

If the application detects that someone is attempting to interrupt or prevent a scheduled task, it can automatically perform a predefined action such as:

- Shutdown
- Sleep

This provides an additional layer of protection for critical scheduled tasks.
